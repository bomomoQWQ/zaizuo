# 在座

对机器人友好的跨平台聊天软件。目标客户端为 Flutter（Linux / Windows / Android）；先实现不含界面设计的 Dart 核心与命令行、OneBot 11/12，以及 Dart 可嵌入 / Go 独立两种哑中继。

## 当前状态

初始化中的独立仓库，不是已完成的 IM。历史讨论保存在 [迁移原件](docs/archive/架构讨论稿-迁移原件.md)，其中包含安全错误和矛盾，不应作为密码学规范。最新实现契约与验证结果会单列记录。

- 产品方向：群聊 / 频道 / 私聊并行；人类主账户可挂多个机器人；茶会、闺房、人机双向论坛与朋友圈。
- 数据方向：本地执行、加密事件、Git 同步；中继只作为可选实时通道。
- 正式项目名：在座；代码标识及平台名：`zaizuo`；OneBot 扩展前缀：`zaizuo.`。
- 本仓库没有复制 NapCat 实现、二进制或许可证；架构讨论原稿从本机既有资料迁移，保留出处。
- 项目许可证待定。未经维护者确认不发布，不自动创建远端、不推送。

# 换设备继续开发

源码仓库：<https://github.com/bomomoQWQ/zaizuo>，默认分支 `main`。这是**开发代码仓库**，不是在座社区的聊天数据/Git传输仓库；不要直接把它填入 `ZAIZUO_GIT_REMOTE`，也不要往里面上传真实账户资料。

## 1. 克隆代码

建议选择纯英文、短路径，避免已复现的 Windows 原生编译器 Unicode 参数问题：

```sh
git clone https://github.com/bomomoQWQ/zaizuo.git
cd zaizuo
git status
git log -5 --oneline
```

公开仓库可匿名克隆；要继续推送，请在新设备通过 Git Credential Manager、GitHub CLI 或 SSH 登录你自己的 `bomomoQWQ` 账号，不从旧设备导出或复制明文 token/私钥。

项目原创代码按维护者明确选择采用 [AGPL-3.0-only](../LICENSE)，见[声明](../NOTICE)。修改、分发及远程网络交互版本应按许可履行相应源码提供义务；第三方依赖保留其各自许可，不套用NapCat许可证。

## 2. 工具链与依赖

本轮实际验证：Dart **3.14.0**，Android 验证壳 Flutter **3.50.0**（自带同版 Dart），Windows Git **2.55.0** / Ubuntu Git **2.43.0**。独立 Go 中继实际使用 Go **1.27.4**；模块声明的最低版本并不代表整个最低版本兼容矩阵已验收。

- 只开发非界面内核/CLI：安装 Git 与 Dart 即可，不需要 Flutter、Go、cwebp 或 Android SDK。
- 开发 Android 验证壳：安装 Flutter3.50.0，可使用 Flutter 自带 Dart，不必重复装第二套。Android 构建还需对应 JDK/SDK/NDK，详见 [Android构建](Android构建.md)。
- 开发独立中继：额外安装 Go；可嵌入 Dart 中继不要求 Go。
- 不复制旧电脑 `.local/` 中整套工具与用户缓存。选择可信官方分发、核对版本；不要自动升级依赖锁来修构建错误。

每个 Dart 包独立获取依赖。本项目暂不是 Dart pub workspace：

```sh
cd packages/runtime
dart pub get --enforce-lockfile
dart analyze
dart run bin/zaizuo.dart --help
cd ../..
```

运行全套测试前，分别对 `packages/core`、`packages/domain`、`packages/relay_dart`、`packages/onebot`、`packages/runtime` 执行：

```sh
dart pub get --enforce-lockfile
dart analyze
dart test --reporter expanded
```

真实 Git 集成测试可能需要数分钟；不要为了快速变绿改成mock或忽略失败。Go 中继在 `relay-go` 下执行 `go test ./...`、`go vet ./...`、`go build ./...`。

Android 验证壳在 `apps/mobile_probe` 下执行 `flutter pub get`、`flutter analyze`、`flutter test`。它目前没有 Android Git 或跨机 IM，不能当作完整手机客户端继续依赖。Gradle wrapper启动脚本/JAR按Flutter模板约定不提交Git，固定的`gradle-wrapper.properties`已提交；Flutter构建工具会在需要时从其官方工具缓存注入缺失wrapper。不要用`flutter create .`覆盖本项目的自定义Java入口或Gradle配置。

## 3. 没有上传的本机内容

以下不在源码仓库里，`git clone` 不会得到：

- `.local/` 里的 Dart/Flutter/Go/Android SDK、缓存、测试账号、私密资料和诊断日志。
- `dist/`、`build/` 的 ZIP、DEB、APK、AOT、可执行程序不进Git历史；已验证的四个测试包另在[GitHub预发布页](https://github.com/bomomoQWQ/zaizuo/releases/tag/v0.1.0-media-test3)提供下载，附SHA-256清单。下载测试包不需要克隆源码；Android仅验证壳，不能当完整手机端使用。
- SSH 私钥、Git/GitHub登录状态、在座密码、第二因素和恢复材料。

新设备首次运行建议初始化新的丢弃式测试资料，正常CLI仍使用默认强KDF。`tools/cross_host` 内置公开假测试口令与tiny KDF，只用于临时测试，不能用于真实账号。

如果需要迁移真实在座账户，必须另做受控设备授权或资料迁移；代码同步不等于账号或解密密钥同步，不要直接 `git add` profile。

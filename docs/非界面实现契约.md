# 在座：非界面实现契约（实施中）

## 目标与分层

1. `packages/core`（包 `zaizuo_core`）：规范化序列化、账号密码加密钥匙箱、Ed25519 签名与 X25519 密钥封装（两种用途分开）、扫码配对数据、每设备事件链、本地持久化、Git 存取。
2. `packages/domain`（包 `zaizuo_domain`）：纯业务状态机；主账户与机器人、关系、群聊/频道/私聊、权限、茶会/闺房、论坛/朋友圈、配额。只操作已认证的调用主体，不持有网络凭据。
3. `packages/onebot`（包 `zaizuo_onebot`）：11/12 双投影、本地 HTTP/WS/反向 WS、鉴权与错误映射。不得靠自报 `self` 切换到未授权机器人。
4. `packages/relay_dart`（包 `zaizuo_relay`）与 `relay-go`：同一不透明转发协议，不含业务逻辑。
5. 命令行与本机集成测试验证核心，不做 Flutter 页面或视觉设计。

## 历史讨论必须修正的错误

- 哑中继是服务端程序，有连接和队列的临时状态，不是“没有服务端”。不保存历史不等于绝对不会丢消息。
- Git 协作账号凭据和在座账号密码是不同的两道门。不自动索取、共享社区创建者的高权限 GitHub 令牌。
- 签名用 Ed25519；加密密钥封装用 X25519 + HKDF + AEAD，不能拿 Ed25519 公钥直接加密。
- 泄露后轮换不得把新密钥只用旧密钥加密，否则持有旧密钥的人跟着拿到全部未来密钥。每一期会话密钥独立随机生成，重新按当期合法接收者封装。
- 账号密码解开的仓库钥匙箱如果包含全部根私钥，会绕过“扫码第二因素”。开启扫码授权后须再有仓库外的高熵解锁材料，或可信已授权设备的批准；不能只在界面加检查。
- 公开频道“无需审批加入”与“密钥递送”分开：现有成员自动响应合法加入事件，不把密钥递送误写成人工准入审批。无人上线可能等待。
- 私有仓库不隔离内部会话；只有独立会话密钥和接收者列表才能隔离。看过的人无法被迫忘记，旧密钥收不回。
- 纯 Git 无中心不存在全局时间戳游标。逻辑时钟用于排序；每设备独立连续序号与前事件哈希链用于检测缺口；不能只记“最高逻辑时钟”。
- 明文附件摘要不放进公开对象名，避免确认“某敏感图片是否存在”；密文对象可用密文哈希寻址，同一事件只加密一次，副本转运原封不动。跨会话不做可观察的全局明文去重。
- 签名只能验证出处/未被改动，不能阻止托管方删数据或回滚。需本地钉住信任根和已见分支头，拒绝不明回退与分叉。
- 每设备分支只消除共同写一个分支的冲突；多个设备写 `main` 仍有并发问题。`main` 只承载社区根配置和授权检查点，日常变更以各设备签名事件发布并本地归并。
- Git 不是无限容量对象存储；部分克隆不等于浅克隆，省本地下载不省托管方容量。吞吐与国内延迟必须实测，不再引用拍脑袋数字。
- 无撤回是产品决定，不妨碍本地隐藏或社区屏蔽违规内容；不是“技术上永远不可能删除任何文件”。
- OneBot 11 也支持 `echo`；12 的事件 ID 为唯一字符串，不要求 UUID；扩展前缀是规范建议（在座内部强制）。只有通过协议测试才能声明实现子集兼容，不因返回版本号即宣称完整兼容。

## 本轮核心最小公开接口约定

用各包自己的 `toJson/fromJson` 及不可变字段，时间用 UTC Unix 毫秒内部表示、OneBot 边界转秒。JSON 协议编号一律字符串，测试用可读编号亦可，业务不能拿昵称做授权键。

业务包独立于加密包，公开：

- `ChatState`：可 `toJson()` / `ChatState.fromJson(Map<String,dynamic>)` 持久化；`ChatService(ChatState state, {DateTime Function()? now})` 是唯一业务写入口。
- `Actor`：`id`（人或机器人的稳定编号）、`ownerId`（主账户编号）、`isBot`；不能把 owner 权限自动继承给 bot。
- `ChatService` 提供 `actor(String principalId)` 解析已存在主体，所有写方法必须接收 `Actor actor` 且核对服务端/调用上下文中该身份合法存在。投影入口的 bot 绑定来自本地凭据配置，不采用请求自报身份。
- 业务 JSON 消息段为 `List<Map<String,dynamic>>`；`MessageRecord` 至少 `id, conversationId, senderId, parts, createdAtMs`，保存原始发送身份。
- 稳定方法（具名参数），具体返回字段由实现文档补齐：
  - `registerAccount({required String id, required String name, required String displayName})`
  - `registerBot({required Actor actor, required String id, required String displayName})`
  - `createSpace({required Actor actor, required String id, required String title, required bool publicChannel})`
  - `joinSpace({required Actor actor, required String spaceId, String? botId, bool invited = false})`
  - `decideJoin({required Actor actor, required String spaceId, required String principalId, required bool approve})`
  - `leaveSpace({required Actor actor, required String spaceId, String? botId})`
  - `sendMessage({required Actor actor, required String conversationId, required List<Map<String,dynamic>> parts, String? idempotencyKey})`
  - `directConversation({required Actor actor, required String targetId})`
  - `messages({required Actor actor, required String conversationId, int limit = 50, String? beforeId})`
  - `conversations({required Actor actor})`, `friends({required Actor actor})`, `members({required Actor actor, required String spaceId})`
- `DomainException`：`String code` + `String message`；比如 `forbidden`, `not_found`, `quota_exceeded`, `bad_request`, `rate_limited`。协议层分别映射 11/12，不把核心绑定到某个返回码。
- 列表查询也必须按调用者读权限过滤，不能“只限制发送不限制历史”。

## 实现边界

本轮允许先交付可测试的非界面原型，不把协议/密码学原型宣传为经审计的生产版本。Android 的系统密钥库、调度、通知与后台真实耗电只能真机验收，Dart 桌面单元测试不等于完成 Android 集成；不得使用恶意保活或规避系统限制。

# 哑中继协议 v1（原型）

## 范围

Go 独立程序与 Dart 可嵌入模块使用相同线协议。中继只在内存维护连接、订阅、有限发送队列；不读 Git、不保存历史、不解密、不替客户端判断账号与会话权限，不实现 OneBot。连接令牌只是防止陌生人占用资源，不是聊天记录的授权边界。

## 连接

- `GET /v1/ws`，标准 WebSocket 升级。
- 必须携带 `Authorization: Bearer <token>`。令牌为 32～256 个 ASCII 可打印非空白字符，仅本地配置，不放 URL，不写日志；两端比较相同密钥派生的固定长摘要，避免直接早停字符串比较。
- v1 拒绝任何带 `Origin` 请求头的连接（本轮不支持浏览器；Flutter 三端原生与 Dart/Go 不受影响），避免网页偷偷使用本机服务。允许无 Origin 的原生客户端。
- 不接受查询串和非 GET 请求。未授权返回 HTTP 401，浏览器来源返回 403，错误路径 404，不回显凭据。
- 仅文本 WebSocket 消息，正文为单个 JSON 对象；禁用 WebSocket 压缩。收到重复 JSON 键为未定义格式，发送端禁止生成，接收端不以 JSON 字段内容作为业务安全依据。
- 连上发送 `{"op":"ready","version":1}`。该消息不是数据持久化回执。
- `GET /healthz` 无需令牌，仅返回 `ok\n`；不暴露连接、主题、账号数据。

## 标识和字段

- `topic`：恰好 64 个小写十六进制字符，是客户端生成的不可读路由标签。不是群名、不是会话密钥。知道标签和连接令牌就能订阅密文，真正隔离靠端到端加密。
- `request_id`：1～64 个 ASCII 英文、数字、下划线或短横线。仅用于本连接内关联响应，发送端负责不复用未完成的编号。
- `payload`：非空、规范的标准 Base64（带应有的 `=`，不允许空白或 URL 安全变体），解码后最多 32768 字节。内容是已经加密并签名的完整事件信封，中继不解析内部字段。
- v1 请求仅允许各操作列出的字段；拒绝未知字段、错误类型、无效 JSON。发送者订阅一个主题之后才可向它发布（资源规则，不代表业务授权）。

## 请求与响应

订阅（幂等）：

```json
{"op":"subscribe","request_id":"s1","topic":"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"}
```

取消订阅（幂等）：

```json
{"op":"unsubscribe","request_id":"u1","topic":"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"}
```

发布：

```json
{"op":"publish","request_id":"p1","topic":"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa","payload":"AQID"}
```

成功：

```json
{"op":"ok","request_id":"s1","for":"subscribe","topic":"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"}
```

对其他已订阅连接转发，不回送发布者（但同账户的其他连接仍收到）：

```json
{"op":"event","topic":"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa","payload":"AQID"}
```

错误：

```json
{"op":"error","request_id":"p1","code":"not_subscribed"}
```

不能安全读取 `request_id` 时省略它。错误码：`bad_request`（格式/字段/编码错误）、`unsupported_op`（未知操作）、`not_subscribed`、`too_many_topics`。错误响应不回显正文、令牌或任意输入字符串。

`publish` 的 `ok` **只表示中继处理了这一帧**，不表示任何收件人已收到、写盘或进 Git；无人订阅也可成功。单连接请求按到达顺序处理，不保证跨连接全序，不做重复发布去重。客户端必须用事件编号去重，并经 Git 补齐缺口。

## 资源边界

两种实现的默认值一致，配置值必须为正数：

| 项 | 默认 |
|---|---|
| 总连接数 | 128 |
| 单连接订阅上限 | 64 |
| 文本帧 UTF-8 大小 | 65536 字节 |
| 单 payload 解码大小 | 32768 字节 |
| 单连接待发送队列 | 32 条 |
| 单连接固定窗口请求上限 | 每 10 秒 100 条（包括错误请求） |
| 心跳间隔 | 30 秒 |
| 写入/关闭宽限 | 5 秒 |

- 超额连接 HTTP 503；速率超限 WebSocket 1008；超大消息 1009；二进制消息 1003。
- 慢收件人（队列满/写超时）关闭 1013，不阻塞其他连接；客户端断线后按 Git 补拉，不能假装成功持久化。
- 使用 WebSocket ping/pong 检测失活。Go 关闭宽限默认允许两个心跳周期；Dart `pingInterval` 按库语义，一个周期内未响应会关闭，二者关闭时点不保证毫秒级相同。
- 内存状态会随进程退出全部消失；停止服务关闭所有现有 WebSocket，不能只停止 HTTP 监听。

## 安全与部署

- 默认只监听 `127.0.0.1`。跨主机连接必须显式改监听地址，并使用 TLS/WSS 或可信加密组网。共享令牌不能在公网裸 WS 上传输。
- 中继能看到连接 IP、流量、路由标签和时间。端到端加密只能保护内容，不隐藏这些元数据。
- 不提供 NAT 打洞、自动选主、自动互联或公网发现；客户端兼任并不会自动变得可从外网访问。
- 本协议不是客户端加密协议，不能据此声称已经实现用户账号、多因素验证、密钥轮换或 OneBot 兼容。

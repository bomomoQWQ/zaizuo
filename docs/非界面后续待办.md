# 非界面后续待办

这是对**未完成内容**的明确清单，不因界面未做就把底层缺口划进“前端工作”。本轮已有可运行、已测试、本地提交的原型；以下条目完成前不称产品可正式部署。

## P0：账号与端到端安全生命周期

- [ ] 桌面系统安全存储：Windows DPAPI、Linux Secret Service；Android Keystore独立适配。当前随机第二因素仍存本机文件，不等于设备失窃防护。
- [ ] 设备配对完整应用流程：现有签名请求/批准/第二因素封装原语接入本机资料创建、钥匙箱复制、名册设备登记和持久一次性挑战账本。只有内存防重放不能承诺重启后一次性。
- [ ] 账号密码修改、第二因素更换、设备吊销、设备全部丢失、失窃恢复及根轮换：明确历史密钥留存、重新分发与撤权时点，不能用旧密钥封装新密钥伪恢复。
- [ ] 多文件资料写入的崩溃恢复：当前签名检查点冲突会拒绝打开，尚无完整事务恢复/断电验收。部分期次分发失败会封门，需从日志检查恢复，不是全收件者原子发送。
- [ ] 无中心并发换钥的冲突裁决、离线权限事件竞态与名册水位：现状检测冲突并锁止，不承诺自动解决。不能用放宽校验修“可用性”。

## P1：非文字内容与网络传输

- [x] 默认真实图片编码：精确锁定纯Dart image4.12.0，lossless/exact WebP，尺寸/像素/字节/时间限制；Windows/Ubuntu逐RGBA验证。isolate不是OS沙箱，codec缺陷/硬CPU内存预算仍需独立审计。
- [x] 密文附件Git对象分支、精确按需拉取、对象hash/pin与大小/本机缓存配额；不公开明文摘要去重。大文件断点续传、总仓库配额、断电及磁盘故障恢复仍未完成。
- [x] OneBot12标准data上传/下载、11在座扩展、授权本机file_id生命周期及真实Node媒体端到端测试；拒绝任意URL/路径，跨bot不借句柄，原消息权限每次重查。
- [ ] 可选公开WSS客户端/部署TLS验证、受限握手和重定向防凭据泄露。当前应用RelayLink只支持数字loopback测试端点。
- [x] Windows/Ubuntu真实局域网SSH/Git：独立账户/资料，经根签名入驻、名册和密文事件、文件/透明图片双向链路实测。只使用用户授权隔离目录，未创建GitHub远端。
- [ ] GitHub/HTTPS与真实公网：用户独立凭据、受保护main、访问撤销、pack硬流量/超时资源约束；不把局域网通过冒充公网验收。
- [ ] 关系隐藏若成为产品要求：将全社区控制密文改为定向控制信箱；现有协议泄露会话关系/收件者与授权时间，不只泄露IP。

## P1：跨平台运行（不是界面设计）

- [ ] Android Git库/传输，不假设存在命令行git；进程限制、文件锁与安全目录实机验证。
- [ ] Android后台调度、网络电量约束与实测耗电，明确系统延迟，不保活刷存在感。
- [x] Windows/Linux CLI原生分发：Windows AOT快照+配套运行时zip、Ubuntu原生tar.gz及deb，实际解包运行默认KDF初始化、文件/图片收发、下载与重开；不需另装Dart。
- [ ] Windows单文件EXE的gen_snapshot Unicode绝对参数缺陷、Dart声明最低版本与旧glibc/arm64矩阵验证；当前snapshot便携包不是单EXE。
- [ ] 完整Android跨机客户端与真机测试；最小本机验证壳及APK构建单独见Android构建文档，不冒充完整端。
- [ ] Go race在有CGO编译器环境验证；Docker实际构建、非root与关闭流程测试。

## P2：兼容性和规模

- [ ] AstrBot/NoneBot等真实框架本机测试：协议动作清单通过不代表全部插件兼容。
- [ ] 明确OneBot扩展论坛/朋友圈事件通知语义，标准动作不能乱冒充平台消息。
- [ ] 增量重放与可信检查点，替换原型全量重验；大社区压力/内存/启动/同步时延测试。
- [ ] Git历史删除、托管容量不足、备份恢复与异常人工处置工具。
- [ ] `historyVisibleToNewMembers=true`显式分享旧epoch方案：当前manager只安全发当前期次，默认false隔离已测；不能为了支持开关直接把所有旧key发新人。
- [ ] 额外产品能力如空间转让/销毁、好友双向申请：与当前直接关系命令明确区分，再由维护者确定，不自行替换已定产品设定。

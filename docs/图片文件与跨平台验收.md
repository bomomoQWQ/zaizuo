# 图片、文件、真实跨电脑与分发包验收

日期：2026-11-13。这里只记录实际执行过的结果，不是正式产品、第三方密码学审计或完整 Android IM 的完成声明。

## 已完成的关键链路

1. 图片默认采用精确锁定的纯 Dart `image 4.12.0`：检查 PNG/JPEG/静态 WebP，默认 lossless/exact WebP，保留解码后透明 RGBA，剥除原图元数据。默认输入/输出 8 MiB；编码器另有像素、边长与期限限制，不把 isolate 称为 OS 沙箱。JPEG 不能恢复压缩前信息；16-bit 输入降为 8-bit 不称原始逐位无损。
2. 本机上传先用随机独立 stage key 加密，随机 `file_id` 仅属于本机特定主体。发送时重新验证业务权限和原附件读取资格，再用目的 scope/当前 epoch 重新加密。
3. 附件 Git 分支 `attachment/<ciphertext SHA256>` 只含普通 `object.bin` 密文，不含明文文件名、MIME、明文摘要或解密密钥。已验证的加密事件内保存描述；有 Git 时先发布附件对象，再允许消息引用，读取按需精确获取。
4. CLI 已有 `send-file`、`send-image`、`messages`、`download`。下载每次重查原消息权限，仅写用户明确选择的新输出路径，不使用远端文件名决定路径。
5. OneBot 12 的 `upload_file/get_file` 支持 data 模式；11 使用 `zaizuo.upload_file/zaizuo.get_file`。拒绝 URL/任意本机路径、自报 descriptor、跨 bot 借句柄及 scope/epoch 篡改。

实现与更完整 API 边界见 [媒体管线](../packages/runtime/MEDIA.md)、[Git 同步](../packages/core/GIT_SYNC.md) 和 [OneBot 支持矩阵](../packages/onebot/README.md)。

## 真正跨电脑执行，而非两个本机目录

- Windows：独立 Alice 测试资料，Dart 3.14.0、Git 2.55.0.windows.1。
- Ubuntu：维护者授权的 `bomomo@192.168.1.15`，Ubuntu 24.04.4 x86_64、Dart 3.14.0、Git 2.43.0。
- 只使用既有 OpenSSH 身份、严格 host-key 检查和 `/home/bomomo/zaizuo-lab/` 隔离目录；没有读取或导出 Xshell 私钥，没有 sudo、系统包安装、防火墙或现有服务修改，没有把社区根私钥交给另一台电脑。
- 远端使用专用裸 Git 仓库。两台机器分别初始化账号；仅交换公开 manifest/加入请求和仓库外确认的根指纹，由根账户签名接纳 Bob。名册修订、两条设备密文分支和附件分支均实际通过 Git/SSH 传输。

往返文件 SHA-256：`cd04162b0369674b6a231e53f8e460d1ab68145b60593c106d62718bdad21807`。远端为测试密文附件分支、两条设备分支及根名册 main；这次文件较小，不代表大文件或弱网压力已测。

可复现阶段程序为 [跨机测试 peer](../tools/cross_host/bin/peer.dart)。它内置**纯测试口令与 tiny KDF**，只能用于新建的丢弃式测试资料；禁止拿它初始化真实账号。正常 CLI 初始化仍使用 64 MiB / 3 轮 KDF。测试仓库和资料保留于忽略目录供检查，不加入源代码仓库，不自动删除用户服务器数据。

实际验收：

- Windows 原生 AOT 编译 → 显式 allowlist 组装 ZIP → 新目录解压 → 64 项包内摘要全部匹配 → launcher `--help`。
- Ubuntu 实际原生编译 → tar.gz 和 `dpkg-deb` 生成 → 无 root 解包 → 包内 SHA-256 全匹配 → 便携 launcher 与 DEB 提取出的 launcher 均运行成功。没有安装到服务器系统目录。
- 两个平台均对**真正解压包中的程序**运行 [包级媒体烟测](../tools/package/smoke_package.dart)：默认 KDF 初始化 → 新进程重开 → 建频道 → 1 KiB 二进制发送 → PNG 实际转 WebP → 消息查询 → 两种附件明确路径下载 → 文件逐字节一致 / 图像确为 RIFF/WEBP → 再次重开。不是用 `dart run` 源码冒充已打包程序。
- Windows 包为 AOT snapshot 加同版 `dartaotruntime.exe`，不是单文件在座 EXE。标准 `dart compile exe` 的 Unicode 参数缺陷仍单列；未更改 ACL、执行策略或杀毒配置来掩盖错误。
- 本机 PowerShell 脚本被 AuthorizationManager 拒绝，未将改策略/换壳求值当解决办法；实际是直接执行已允许的 native 构建阶段。脚本仅语法检查，不能称整份脚本已运行。

最终用户不需 Dart SDK；同步仍需自行管理 Git 和凭据。默认图片处理不需 cwebp。构建、安装、依赖及未签名边界见 [构建与安装](构建与安装.md)。

## Android 和剩余边界

Android arm64 debug APK 已实物生成，`apksigner verify` 验证通过；读取最终 merged manifest 确认 minSdk24（Android7+）、target34、compile36，备份关闭、无 INTERNET/存储/相机权限。构建及逐项产物验收见 [Android 构建记录](Android构建.md)。最小壳只做应用私密测试资料、真实图片编码/密文落盘/解密预览；没有 Android Git、跨电脑 IM、系统 Keystore、后台调度或正式 UI。APK 构建成功也不等于已在手机安装运行，本轮未进行真机或模拟器安装。

仍未验证/未完成：GitHub/HTTPS 和公网网络、完整 Android 跨机客户端、arm64 Linux/旧 glibc 矩阵、断电/磁盘故障原子恢复、大文件断点续传、系统安全存储及恢复、正式签名/升级渠道、第三方密码学审计和真实外部机器人框架。默认 256 MiB 本机附件缓存满时拒绝新对象，不自动删除历史；磁盘失败可能留孤立密文但仍计入总量，不宣传失败绝无残留。post-only 且无 history.read 的机器人发媒体后，回执投影可能因无读权限失败；不是绕权放行。
